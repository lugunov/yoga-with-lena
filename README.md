# Yoga with Lena 🌿

Статический сайт для йога-тренера.

## 🚀 Запуск локально

Так как проект теперь полностью статический, достаточно открыть `index.html` в браузере.

Альтернативно можно поднять простой локальный сервер, например:

```bash
python -m http.server 8080
```

И открыть:

```text
http://localhost:8080
```

## 📁 Структура проекта

- `index.html` — основная страница
- `styles.css` — стили
- `app.js` — клиентская логика (язык RU/EN, текущий год)
